# Log Management Guide for Casino Calendar

This guide describes the **current** logging and cleanup workflow used by the app and maintenance scripts.

## Current Log Files

By default logs are written under `logs/`.

- `app.log` — primary application log (override with `LOG_FILE`)
- `casino_calendar_maintenance.log` — maintenance/test script output (override with `MAINTENANCE_LOG_FILE`)
- `casino_calendar_http.log` — optional HTTP access log when HTTP capture is enabled
- `archive/` — archived monthly and cumulative log files generated by cleanup tooling

## Common Commands

Run these from the repository root.

```bash
# Show log directory information
python scripts/python/cleanup_logs.py --info
scripts\windows\cleanup_logs.bat --info

# Preview cleanup actions without deleting
python scripts/python/cleanup_logs.py --dry-run
scripts\windows\cleanup_logs.bat --dry-run

# Remove entries older than 30 days (default)
python scripts/python/cleanup_logs.py
scripts\windows\cleanup_logs.bat

# Use a custom retention period
python scripts/python/cleanup_logs.py --days 7
```

## Startup Archiving

The app supports startup-time archiving of the active application log:

- `ARCHIVE_APP_LOG_ON_STARTUP=move` — move active log entries to archive before app starts
- `ARCHIVE_APP_LOG_ON_STARTUP=copy` — copy active entries to archive and keep active log intact
- `ARCHIVE_APP_LOG_ON_STARTUP=false` — disable startup archiving (default)

## Maintenance Logging Environment Variables

- `MAINTENANCE_LOG_FILE` — maintenance log destination
- `MAINTENANCE_LOG_LEVEL` — console verbosity for maintenance scripts
- `LOG_FILE_TZ` — timestamp mode for file logs (`UTC` default, `LOCAL` optional)

## Recommended Retention

- Development: 7–30 days
- Shared/staging: 30–90 days
- Production/compliance contexts: 90+ days (based on policy)

## Troubleshooting

```bash
# Verify cleanup script options
python scripts/python/cleanup_logs.py --help

# Quick environment check
python scripts/python/check_environment.py
```

If cleanup is not behaving as expected, verify write permissions for `logs/` and confirm your environment variables are set as intended.
