# AGENTS Instructions for casino-calendar

This repository contains a Dash web application. These instructions apply to the entire repo.

## Code style
- Follow standard Python 3 syntax and conventions (PEP 8).

## Programmatic check
- After making changes, run `python -m py_compile app.py app_components/*.py` and ensure it exits without error.

## Pull request message
- Provide a concise summary of the changes using bullet points.
- Include a testing section describing the result of the programmatic check.
